## Verified visual fixes

During capture, the mobile layout was found to retain an oversized desktop sidebar. The authenticated navigation was changed to an icon rail at small widths while retaining full labels on desktop. The image dialog was also found to advertise SVG even though the hardened server intentionally rejects active SVG documents; the client guidance and file accept list were corrected to JPEG, PNG, GIF, and WebP. The final screenshots were recaptured after both fixes.

## Evidence limitations

These are local/test screenshots, not production screenshots. They prove the actual functioning application on the exact application source SHA, authenticated with deterministic demo data. They do not prove production deployment parity, production storage durability, real AI-provider credentials, or production runtime health.
