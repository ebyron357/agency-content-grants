## Sourcing rules applied

- Every factual claim cites the file it came from.
- Where the repository contains no data — notably billing, pricing, customers and the production host — that absence is stated plainly rather than filled with placeholders.
- Cost and valuation figures are labelled as estimates with their assumptions shown; no vendor price or commercial fact is asserted as verified.
- No credential values appear in these pages.

## Relationship to governing documents

These pages are descriptive. They do not override `AGENTS.md`, `docs/GO_NO_GO_DECISION.md` or `docs/PROJECT_STATUS.md`, which remain the authoritative governance, authorization and status records.
